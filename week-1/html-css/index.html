About Me Lesson
  • Element - building block of html
  • Most elements have opening and closing tags
  • Some elements have self closing tags ex: img
  • Elements are like boxes
  • We can fix box inside of another box inside of another box
  • Attributes - live inside an element and provide it with extra functionality
  • Some examples common attributes are id, class, style, for, etc.
